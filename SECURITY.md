# Security

Better Monitor's public repository contains product documentation and release materials. The application source code is not public.

## Reporting a security concern

Please do not publish security vulnerabilities, private diagnostics, credentials, API keys, or other sensitive information in a public issue.

Email [support@bettermac.net](mailto:support@bettermac.net) with `Security report` in the subject. You can also use the [Support Center](https://bettermac.net/en/support/?product=better-monitor) or [Contact Us](https://bettermac.net/en/contact/?product=better-monitor). Ask support for a private channel before sending sensitive details; the public contact pages do not provide a dedicated security mailbox or encryption instructions.

There is no public security-response SLA in this repository. The support team can confirm the current handling and support status for your release.

## Supported release information

The repository currently documents Better Monitor 1.0.1. Check the [latest release](https://github.com/BetterMacNet/better-monitor/releases/latest) and contact support to confirm whether a particular release is still supported.

## Privacy when reporting

Before sharing logs or screenshots, remove API keys, credentials, personal information, private file paths, process arguments, network addresses, and other data that could identify you or your system.
