# Better Monitor

[English](README.md) · [简体中文](README.zh-CN.md) · 日本語 · [한국어](README.ko.md)

<img src="assets/logo.png" alt="Better Monitor" width="160">

いま Mac で何が起きているかを把握するための、ネイティブな macOS システムモニタです。

Better Monitor はプロセス、ネットワーク、ポート、ログイン項目、ハードウェアの情報を 1 つのアプリにまとめ、日々の確認にも的を絞った調査にも使えます。

![Better Monitor の監視概要：健全性スコア、CPU、メモリ、ネットワーク、ディスク、プロセス、放熱の状態と提案](screenshots/ja/01-overview.webp)

## こんなときに

- CPU、メモリ、ディスク、ネットワーク、バッテリー、センサー、プロセスの状態をまとめて確認したい。
- CPU やメモリを異常に使っているアプリやプロセスを見つけたい。
- アクティブなネットワーク接続、通信量、プロトコル、接続先を確認したい。
- 待ち受け中のポート、その所属プロセス、リスクのサインを確認したい。
- バックグラウンドで自動起動する項目と、その現在のリソース影響を確認したい。

## クイックスタート

1. Better Monitor をインストールします：

   ```bash
   brew install --cask bettermacnet/tap/better-monitor
   ```

2. Better Monitor を起動し、サイドバーから画面を選びます。
3. 状態をすばやく確認するなら「監視概要」、特定の問題を調べるならプロセス監視、ネットワーク、ポートとサービス、ログイン項目を開きます。
4. 現在の Wi-Fi 名を表示したい場合のみ、位置情報サービスを許可してください。権限やシステムの公開範囲によっては、プロセスやポートの詳細が macOS により制限されることがあります。

[最新リリース](https://github.com/BetterMacNet/better-monitor/releases/latest)からディスクイメージをダウンロードし、`Better Monitor.app` を「アプリケーション」フォルダに移動することもできます。リリースは Developer ID で署名され、Apple の公証を受けており、公証チケットはディスクイメージにステープルされています。

## 主な機能

- **監視概要** — システムの健全性と主要なリソース情報をひと目で確認。
- **プロセス監視** — リソース使用量、識別情報、パス、ネットワーク活動、開いているファイルを確認し、操作できるプロセスには対応するアクションを実行。
- **ネットワーク活動** — インターフェイス、接続、通信量、プロトコル、TCP 状態、接続先を確認。
- **ポートとサービス** — 待ち受けポートとその所属プロセスを特定し、役立つリスクのサインを表示。
- **ログイン項目** — 読み取り可能な LaunchAgents と LaunchDaemons、現在のリソース影響を確認し、macOS が管理するログイン項目はシステム設定から確認。
- **任意の AI アシスト** — ご自身で AI サービスを設定し、必要なときにプロセスの AI 診断を依頼。
- **ネイティブな macOS 体験** — SwiftUI で構築。macOS 15 以降に対応。

## 権限と既知の制限

- 現在の Wi-Fi 名を表示するには位置情報サービスの許可が必要です。Better Monitor がこの権限を位置情報の取得に使うことはありません。
- システムがアプリに公開していない場合、プロセスやポートの詳細は制限されることがあります。
- macOS が管理するログイン項目は、アプリ内で完全に管理するのではなく、システム設定で確認します。
- 非ローカルバインドは確認すべきサインであり、外部から到達できることの証明や、セキュリティ監査の完了を意味するものではありません。
- ログイン項目の影響は現在の実行状態に基づく値で、起動時間の計測でも、無効化による節約の保証でもありません。

## プライバシーと任意の AI

基本の監視はローカルで完結し、アカウントやクラウドサービスは不要です。AI アシストは任意です。

- AI 診断がネットワークを使うのは、AI サービスを設定し、明示的に要約を依頼したときだけです。
- API キーは macOS のキーチェーンに保存されます。
- 診断情報を送信する前に、データ送信の説明が表示されます。
- 依頼には、診断に必要なプロセス、ネットワーク、パス、ファイル活動の概要が含まれる場合があります。有効にする前に、サービス提供者のデータの取り扱いを確認してください。
- アプリ内のローカルな AI 会話と監視履歴は消去できます。消去しても、すでにサービス提供者へ送信したデータは削除されません。
- 診断のために送信したデータには、サービス提供者自身の保持およびモデル学習の規約が適用されます。

AI を設定しなくても、基本の監視機能はすべて使えます。
