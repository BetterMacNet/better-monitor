# Better Monitor 功能介绍

Better Monitor 1.0.0 已公开发布。这是一款面向 macOS 的原生系统监控工具，把日常观察和问题排查需要的信息放在同一个窗口里，不要求你在多个系统工具之间来回切换。

## 监控概览

概览页提供系统状态的快速入口：

- CPU 使用率与核心状态
- 内存使用情况
- 磁盘与网络概览
- 电池与传感器信息
- 当前运行进程
- 系统健康度与需要关注的项目

## 进程监控

进程页适合定位高占用和异常行为：

- 按资源占用查看运行中的进程
- 查看进程身份、路径和资源信息
- 查看进程网络活动与打开的文件
- 在有权限且确认安全时结束进程
- 对支持的进程生成 AI 辅助诊断摘要

## 网络活动

网络活动页将连接状态和流量放在一起：

- 当前网络接口与连接状态
- 上传、下载和吞吐趋势
- 活跃连接、协议和 TCP 状态
- 目标地址与连接数量
- 当前 Wi-Fi 名称（需要 macOS 定位权限）

## 端口与服务

端口页用于快速了解本机正在监听什么：

- 监听端口和传输协议
- 服务名称与所属进程
- 绑定范围和外部可达性提示
- 进程签名状态
- 端口变化标记与风险筛选

非本机绑定或风险信号只是需要进一步核对的提示，不代表服务已被外部访问、已经暴露，或完成了安全审计。

## 启动项

启动项页帮助你减少不必要的后台启动：

- 查看可读取的 LaunchAgent 和 LaunchDaemon，并通过系统设置审查现代登录项
- 查看当前资源影响与运行状态（不是开机耗时）
- 对应用支持的条目执行启用或停用
- 对由系统管理的现代登录项跳转到系统设置审查

## 本地历史与隐私

监控历史默认保存在本机。核心监控不需要账号或云服务；只有在你配置 AI 服务并主动请求诊断摘要时，相关数据才会发送给外部 AI 服务商。

## AI 助手（可选）

AI 功能不是使用 Better Monitor 的前提。启用后，你可以配置自己的 AI 服务，用于辅助理解进程的资源、网络和文件活动。

- API 密钥保存在 macOS 钥匙串中
- 发送前需要确认数据披露说明
- AI 结果仅作为诊断辅助，不替代你的判断
