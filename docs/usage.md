# Better Monitor 使用说明

## 安装与启动

Better Monitor 1.0.1 已通过 Developer ID 签名和 Apple 公证，并已发布到 Homebrew Cask。

使用 Homebrew 安装：

```bash
brew install --cask bettermacnet/tap/better-monitor
```

也可以从[最新发布](https://github.com/BetterMacNet/better-monitor/releases/latest)下载磁盘映像，将 `Better Monitor.app` 拖入「应用程序」文件夹后启动。首次启动无需联网验证公证票据。

首次启动后，从左侧导航选择需要查看的页面。

## 从哪里开始

- 想快速了解系统状态：打开「监控概览」。
- 想找出 CPU 或内存占用高的程序：打开「进程监控」。
- 想确认某个程序是否联网：打开「网络活动」或进程详情。
- 想知道本机开放了哪些端口：打开「端口与服务」。
- 想减少开机后的后台程序：打开「启动项」。

## 查看进程

在「进程监控」中：

1. 按 CPU、内存或其他可用指标排序。
2. 选择进程查看详情。
3. 先确认进程名称、路径和身份，再执行操作。
4. 结束进程前保存相关工作；未保存的数据可能丢失。

系统进程和其他用户拥有的进程可能无法操作，这是 macOS 的权限限制。

## 查看端口

在「端口与服务」中：

1. 查看监听端口列表。
2. 使用筛选器关注外部绑定提示、风险或最近发生变化的服务。
3. 选择服务查看端口、进程和签名详情。
4. 如需结束所属进程，请先确认该服务的用途。

非本机绑定或风险信号不等于外部可达性证明，也不代表服务已经完成安全审计；请将其作为进一步核对的提示。

## 查看网络活动

网络活动页显示当前接口和连接信息。若 Wi-Fi 名称显示不可用：

1. 打开 macOS「系统设置」。
2. 进入「隐私与安全性」→「定位服务」。
3. 允许 Better Monitor 使用定位服务。
4. 返回应用并重新查看网络活动页。

Better Monitor 只使用该权限读取 macOS 提供的 Wi-Fi 名称，不记录或上传你的位置信息。

## 管理启动项

在「启动项」中，先查看当前资源影响和条目详情，再决定是否停用。这里的影响指标来自当前运行状态，不代表开机耗时。由 macOS 系统设置管理的现代登录项保持只读，请通过应用提供的入口前往系统设置。

## 使用 AI 诊断

AI 功能为可选功能：

1. 打开「设置」并配置 AI 服务商。
2. 按提示保存 API 密钥。
3. 阅读并确认数据披露说明。
4. 在进程详情中请求诊断摘要。

AI 请求可能包含用于诊断的进程、网络、路径和文件活动摘要。启用前请确认你选择的服务商和数据处理方式符合你的要求。

## 隐私与数据

Better Monitor 的系统监控数据默认用于本机展示。应用内的本地 AI 对话和监控历史可以清除，但清除不会删除已经发送给服务商的数据。AI 功能只有在你主动配置并请求诊断时才会使用网络服务；对于已发送用于诊断的数据，以服务商自己的保留和模型训练条款为准。更多信息请查看[隐私政策](https://bettermac.net/en/privacy/)。
