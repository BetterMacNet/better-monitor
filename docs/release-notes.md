# Release notes

## 1.0.0 — 2026-09-22

Better Monitor 首个签名、公证版本通过 Homebrew Cask 发布。

- 提供监控概览、进程监控、网络活动、端口与服务、启动项和设置页面。
- 支持进程资源、网络连接、监听端口和启动项的集中查看。
- 支持可选的 AI 进程诊断能力；API Key 保存在 macOS 钥匙串中。
- 监控历史默认保存在本机，联网查询仅在你主动触发相关功能时发生。
- 安装：`brew install --cask bettermacnet/tap/better-monitor`
