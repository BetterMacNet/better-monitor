# Release Notes

## 1.0.0 — 2026-09-22

The first signed and notarized release of Better Monitor is available through Homebrew Cask.

- Monitoring overview, process monitor, network activity, ports and services, startup items, and settings pages
- Centralized views for process resources, network connections, listening ports, and startup items
- Optional AI-assisted process diagnostics, with API keys stored in the macOS Keychain
- Monitoring history stored locally by default; network access occurs only when you explicitly request a feature that needs it
- Install with `brew install --cask bettermacnet/tap/better-monitor`
